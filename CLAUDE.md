# Tesseract website (tesseract.city)

Static site, no build step, deployed by Vercel from `main`. Originally generated by Claude Design as "Design Components".

## How it works
- Each page is a `*.dc.html` file. `support.js` (generated runtime — do not edit) loads React 18 + Babel from unpkg in the browser and renders the `<x-dc>` template.
- `<helmet>` holds the page's `<title>`, meta tags and CSS.
- Template syntax: `{{ expr }}` bindings, `<sc-if value="{{ }}">`, `<sc-for list="{{ }}" as="x">`, `style-hover="..."`, and `<dc-import name="SiteHeader">` to include another component (fetched from `./<Name>.dc.html`).
- Page data/logic lives in `<script type="text/x-dc" data-dc-script>`; it **must** define `class Component extends DCLogic { renderVals() { return {...}; } }`. An empty script block breaks the page — use `class Component extends DCLogic {}` if there's no logic.
- Shared header/footer: `SiteHeader.dc.html`, `SiteFooter.dc.html`. Nav links are in SiteHeader's `links` array.
- Design tokens: `_ds/tesseract-design-system-*/` (colors, type, spacing). Images/video: `assets/site/`.

## Routes (vercel.json)
`/` Home · `/climate-resilience` · `/integrated-development` · `/for-developers` · `/learn-more` (Process.dc.html) · `/about` · `/contact`.
Internal links use these clean URLs, not `*.dc.html`. Adding a page = new `.dc.html` + a rewrite in `vercel.json`.
All routes are one level deep, so relative asset paths (`assets/...`) work; keep it that way or switch to absolute `/assets/...`.
